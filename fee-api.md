# Student Fee Management API Documentation

This module manages student fee records, including generating invoices (dues) and recording payments.

> **Note:** All these APIs require an authentication token (`Bearer YOUR_TOKEN_HERE`).

---

## 1. Generate Fee (POST /api/fees)

Generates a new fee invoice/due for a specific student.

```bash
curl -X POST http://localhost:5000/api/fees \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "studentId": "STUDENT_ID_HERE",
    "feeType": "Admission Fee",
    "amount": 15000,
    "dueDate": "2026-09-01",
    "remarks": "Initial Admission Fee for Class 10"
  }'
```

_(Copy the `_id` from the response to use as `FEE_ID` in payment/update operations)_

---

## 2. Process Fee Payment (POST /api/fees/:id/pay)

Record a payment against a specific fee record. The system will automatically calculate if it's "Partially Paid" or fully "Paid".

```bash
curl -X POST http://localhost:5000/api/fees/FEE_ID_HERE/pay \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "amountToPay": 5000,
    "paymentMethod": "UPI",
    "remarks": "First installment via GPay"
  }'
```

---

## 3. Get All Fees for a Specific Student (GET /api/fees/student/:studentId)

Fetch the complete fee history (both pending and paid) for a particular student.

```bash
curl -X GET http://localhost:5000/api/fees/student/STUDENT_ID_HERE \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

---

## 4. Get All Fees System-Wide (GET /api/fees)

Fetch all fees across the school. You can filter by `status` (e.g., Pending, Paid, Overdue) or `feeType`.

```bash
# Get all overdue fees
curl -X GET "http://localhost:5000/api/fees?status=Overdue" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

# Get all pending Tuition Fees
curl -X GET "http://localhost:5000/api/fees?status=Pending&feeType=Tuition%20Fee" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

---

## 5. Update Fee Record (PUT /api/fees/:id)

Update fee details (e.g., if you made a mistake in the amount or dueDate before it's paid).

```bash
curl -X PUT http://localhost:5000/api/fees/FEE_ID_HERE \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 12000,
    "remarks": "Updated amount due to sibling discount"
  }'
```

---

## 6. Delete Fee Record (DELETE /api/fees/:id)

Permanently remove a fee record (only use if the fee was generated by mistake).

```bash
curl -X DELETE http://localhost:5000/api/fees/FEE_ID_HERE \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```
